# ============================================================
# WLT Social Ads Blocklist
# ------------------------------------------------------------
# Telemetry and ad-serving domains for TikTok, Snapchat,
# Twitch, and Pangle (TikTok's ad network used by 380k+ apps).
# Built in Task 34 (comprehensive research round) and expanded
# with Pangle domains in Task 37.
#
# HONEST LIMIT (TikTok / Twitch):
#   In-feed ads share the same CDN as organic content, so DNS
#   blocking cannot strip them without breaking playback. The
#   scriptlets (twitch-video-swap, twitch-mute-ads) handle
#   stream ads at the MITM layer; DNS only kills the
#   tracking/analytics surface.
#   Snapchat: blocking the full sc-cdn.net root breaks the
#   app, so only ads-interfaces.sc-cdn.net is blocked.
# ============================================================
