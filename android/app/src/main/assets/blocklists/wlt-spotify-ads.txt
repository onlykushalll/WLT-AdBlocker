# ============================================================
# WLT Spotify Ads Blocklist
# ------------------------------------------------------------
# Spotify ad-serving, telemetry, crash reporting, and partner
# audio-ad domains. Created in Task 31 alongside the 3 Spotify
# scriptlets (spotify-ad-intercept, spotify-feature-flags,
# spotify-audio-ad-block).
#
# HONEST LIMIT: The native Spotify app streams audio ads from
# the same CDN as audio content (spclient.wg.spotify.com), so
# pure DNS blocking cannot stop in-app audio ads without
# breaking playback. ReVanced/xManager APK patching is the
# only fully effective route. DNS blocking kills the tracking
# surface and the dedicated ad endpoints listed below.
# ============================================================
